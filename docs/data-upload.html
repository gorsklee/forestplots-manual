ForestPlots.net Training Manual

Data Upload

In this section we assume:

  • you correctly followed the steps from digitising data,
  • you have been trained by a member of the ForestPlots’ team to upload data, and
  • you are preparing data for upload, either by yourself or through a ForestPlots team member.

Data upload format

The way in which you format ForestPlots’ data varies depending on

  • whether your plot is new to or already exists in ForestPlots and
  • how many censuses there are to upload.

Specifically, in ForestPlots, there are four different types of data:

The figure above can help you identify which upload format you need.

Before preparing any upload file, ensure you have completed the steps described in the Digitising Data Section.

Type of Data Where to find the data format
New plots with a single census. Uses the Bulk Import: Single Census Plots template available in the Data Import section of ForestPlots.net.
New plots with two or more censuses Uses the Bulk Import: Multi-Census Plot Data template available in the Data Import section of ForestPlots.net.
Existing plots with one additional census. Uses the tree field sheet for the plot, which can be downloaded from the Data Export section of the plots page on ForestPlots.net.
Existing plots with multiple additional censuses. Uses the Bulk Import: Multi-Census Plot Data

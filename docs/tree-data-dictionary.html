Tree Data Dictionary

This page covers every column used with ForestPlots tree data. Use the search box to find any column by name or keyword, or use the filter arrows on any column heading to narrow by template, requirement level, or units.

The Required column uses four categories:

  • Always — must be filled in for every row in that template.
  • Conditional — required only when a specific condition is met (see the Condition column).
  • Optional — may be left blank.
  • Dry Forest — only relevant for Dry Forest plots; leave blank otherwise.

See the Common Issues and Frequently Asked Questions for more information.
